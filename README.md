# IPO Customer Management

A customer-record management application built with React,
TypeScript, Vite, and IndexedDB.

## Live Demo
[Open IPO Customer Management](https://ipo-customer-management-25f1.vercel.app/#/)

## Features
- Customer record management
- Search and update customer details
- Document upload and preview
- PDF generation
- Local browser storage

## Tech Stack
- React
- TypeScript
- Vite
- IndexedDB / Dexie
- Capacitor for Android
